# 장거리 힘 배분 복기 — AI 상담 입력 계약

`review_pacing.py --format json` 또는 기존 overview의 「장거리 힘 배분 복기」를 읽는다.
숫자 계산은 Python이 담당한다. AI가 원시 GPS를 다시 해석하거나 근거 없는 수치를 만들지 않는다.
새 모델 API 호출/의존성을 추가하지 않고 기존 상담 과정에 이 근거를 제공한다.

1. 먼저 `source`, 대상 날짜, `status`, `quality`, 장비 식별·실측 파워 여부를 확인한다. 백업은 최신 상태라는 뜻이 아니다. 비교가 없으면 다른 활동을 임의로 붙이지 않는다.
2. **관찰**: 초반 90분의 기준초과 이벤트를 구체적인 시점으로 짚는다. 비교창이 있으면 대상/비교의 시점·실제 출력·이전 기록 kJ를 함께 인용한다. “후반 최대 능력이 떨어졌다”로 바꾸지 않는다. 비율을 임의의 진단 임계값과 비교하지 않는다.
3. **질문**: 계획한 오르막·인터벌·동행 페이스인지, 주행 목적·바람·기온·보급·휴식이 달랐는지 중 가장 필요한 맥락 1~2개만 묻는다. 답을 받기 전에 오버페이스·보급 부족·훈련 부족으로 확정하지 않는다.
4. **가설**: 관찰과 사용자 답변으로 가능한 설명을 제시하되, 다른 설명과 미확인 내용을 붙인다. GPS 근접은 같은 코스를 완전히 보장하지 않는다. FTP 앵커는 과거 해당 날짜의 실측 FTP가 아니다. 센서 교체/교정도 확인 대상이다.
5. **다음 비교**: 의도하지 않은 초반 노력이 확인되면 사용자가 바꾸고 싶은 한 구간을 정하고, 비슷한 코스·목적에서 후반 같은 구간의 출력·심박·체감을 비교하도록 제안한다. 데이터만 보고 FTP를 변경하거나 고강도 훈련을 처방하지 않는다.

`early_efforts`의 이벤트는 30초 이동평균을 기준으로 20초 이상 이어진 판정이며 실제 순간 파워 초과와 다르다.
관측구간은 겹칠 수 있어 이벤트 kJ를 합산해 소모량으로 부르지 않는다.
`prior_recorded_kj`는 누락된 시간의 일을 포함하지 않은 하한이다. 심박 차이도 원인의 증거가 아니다.
비교창 선택은 출력 크기를 기준으로 하지 않으며 활동당 하나의 근거를 사용한다. 이는 통제 실험·통계적 유의성 검정이 아니다.

출력은 짧은 관찰 2~3문장 → 필요한 질문 → 답변 후 한 가지 비교 제안 순서로 구성한다.
이력서용 성과나 사용자의 체력 개선 효과를 만들어내지 않는다.
